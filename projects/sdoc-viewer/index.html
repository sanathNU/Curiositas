About

unsdocx

A viewer for Samsung Notes files — .sdocx and the older .sdoc — that runs entirely in your browser.

Why it exists

Samsung Notes can export to PDF, but only from a Samsung device with the app installed. If you have the .sdocx and not the phone, the file is effectively a brick. This opens it in a browser tab instead.

Everything happens locally. The file is never uploaded — no server, no tracking, no external requests — which is also what makes it safe to host as a plain static page.

Your library

Notes you open are kept in this browser, so they're still here next time. Find them under All notes, Recent and Favorites (star a note), and sort them into collections from each note's ⋯ menu. Removing a note from the library deletes this browser's copy only; your original file isn't touched.

Writing on your notes

Hit Annotate above the pages to write on them with a pen (pressure-sensitive with a stylus, at the same weight as Samsung's ink) or a highlighter, in a few colors. The eraser removes whole strokes of yours; Undo (⌘Z / Ctrl+Z) steps back. Shortcuts: P, H, E, and Esc to finish.

Your ink is kept in this browser beside the note; the .sdocx itself is never changed, and the note's own strokes can't be erased. Your ink is part of every download below. With a stylus, a finger scrolls instead of drawing.

What it shows

  • Pages — the full page: ink, imported slides and photos together.
  • Media — images and audio embedded in the note.
  • Structure — the Zip entries inside the file; click a .note or .dat to read it as text or hex.
  • Raw — the parsed document, the engine's diagnostics, and the Zip manifest, as JSON.

Getting it out

  • Download PDF — every page of the note in one PDF, from the button above the pages. Always in light mode, on A4-wide pages.
  • Xournal++ — an editable copy for Xournal++, the free handwriting app for Linux, macOS and Windows. Your ink comes over as real strokes you can keep writing on, erase or recolor; images come along too. Typed text isn't included yet.
  • Save PNG — a single page; hover it and choose Save PNG. On a phone the button is always visible.

PDF and PNG are rasterized at 2× the page size (3200 px wide) on an opaque background, so they stay sharp when printed. Handwriting is kept as drawn, but typed text in the PDF can't be selected or searched.

How it works

An .sdocx is a Zip container, opened here with JSZip. Pages are decoded and drawn by @twango/sdocx, a reverse-engineered parser written in Rust and compiled to WebAssembly. It renders each page to SVG, and the viewer shows that SVG as an image.

Each page SVG is 5–14 MB, so pages render as you scroll rather than all at once. The color mode is baked into the SVG, so switching theme re-renders the pages you can see.

It's still a reverse-engineered parser, so a page can come out incomplete. That's a parser limitation, not lost data — keep the original file, and check the Raw tab for what the engine reported.

Without a browser

To check a file parses from the terminal, cargo install sdocx-cli and run sdocx-cli your-note.sdocx. For vector PDF output, see sdocx2pdf.
