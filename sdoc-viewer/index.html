About

unsdocx

A viewer for Samsung Notes files — .sdocx and the older .sdoc — that runs entirely in your browser.

Why it exists

Samsung Notes can export to PDF, but only from a Samsung device with the app installed. If you have the .sdocx and not the phone, the file is effectively a brick. This opens it in a browser tab instead.

Everything happens locally. The file is never uploaded — no server, no tracking, no external requests — which is also what makes it safe to host as a plain static page.

What it shows

  • Pages — the full page: ink, imported slides and photos together.
  • Media — images and audio embedded in the note.
  • Structure — the Zip entries inside the file; click a .note or .dat to read it as text or hex.
  • Raw — the parsed document, the engine's diagnostics, and the Zip manifest, as JSON.

To get a page out, hover it and choose Save PNG. Pages are rasterized at 2× their size (3200 × 4524) on an opaque background, so they stay sharp when printed. On a phone the button is always visible.

How it works

An .sdocx is a Zip container, opened here with JSZip. Pages are decoded and drawn by @twango/sdocx, a reverse-engineered parser written in Rust and compiled to WebAssembly. It renders each page to SVG, and the viewer shows that SVG as an image.

An earlier version drew the strokes onto a canvas by hand. It broke on anything built from imported PDFs or slides: those pages came out blank, and one garbage pen width in the file (4.05e+31) turned into a page-filling black rectangle. Handing rendering to the engine fixed both.

Each page SVG is 5–14 MB, so pages render as you scroll rather than all at once. The color mode is baked into the SVG, so switching theme re-renders the pages you can see.

It's still a reverse-engineered parser, so a page can come out incomplete. That's a parser limitation, not lost data — keep the original file, and check the Raw tab for what the engine reported.

Without a browser

To check a file parses from the terminal, cargo install sdocx-cli and run sdocx-cli your-note.sdocx. For vector PDF output, see sdocx2pdf.
